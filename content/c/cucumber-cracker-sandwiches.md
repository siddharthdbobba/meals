This started as a bread-and-butter tea sandwich and does not survive a pack. Soft bread turns to paste against a cucumber slice within an hour, so the base here is a cracker or a dense rye that takes moisture slowly. Everything else about it travels fine.

Cream cheese and cucumber both need cold, so this is a cooler recipe and a day-one-or-two recipe. Dried dill replaces fresh at about half the volume. The Worcestershire is not there for a flavor you can name; it keeps the spread from tasting flat, which plain cream cheese does once it warms up.
